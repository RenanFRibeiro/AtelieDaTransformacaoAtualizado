Coloque suas imagens de carousel nesta pasta ou use o script ../../scripts/import-carousel-images.ps1 para importá-las via diálogo.

Recomendação de nomes: slide1.jpg, slide2.jpg, slide3.jpg — o componente carregará as imagens por ordem alfabética (ou slide1, slide2...).
Formatos suportados: .jpg .jpeg .png .webp .gif

Para importar pelo script (Windows):
1. Abra PowerShell na raiz do repositório.
2. Execute: .\scripts\import-carousel-images.ps1
3. Selecione as imagens na ordem desejada e clique em Abrir.

Após adicionar imagens, recarregue a aplicação web — o carousel usará automaticamente os arquivos da pasta.
